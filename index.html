⚙️ 班級手機連線指引與網址設定

為什麼手機掃描會無法連線？
當本檔案直接在電腦本機打開時，網址為 file:/// 或 localhost，外部手機無法解析這個路徑。

最佳解決方案（三擇一）：
  1. 雲端部署（推薦，最穩定）：將此單一 HTML 檔案上傳到 GitHub Pages、Netlify、Vercel 等免費靜態空間，手機掃碼即刻連通。
  2. 教室區網 IP 連線：若電腦使用 Live Server 或 Python 伺服器開啟，可在下方輸入你的電腦區網 IP（如 http://192.168.1.5:5500），QR Code 會立刻更新。
  3. 單機傳閱模式：無網路環境下，直接在大螢幕點選同學名字進行私密翻牌，免手機亦可暢玩！
